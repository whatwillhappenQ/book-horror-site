# AGENTS.md — Book Horror Site

Ты работаешь над проектом интерактивного сайта-книги.

Главный канон проекта:
- Файл docs/сайт.txt — главный сценарий.
- Нельзя упрощать сценарий.
- Нельзя выкидывать детали.
- Нельзя превращать проект в обычный лендинг.
- Если есть сомнение, выбирай вариант ближе к docs/сайт.txt.

Тип проекта:
- Это сайт/PWA, не отдельное приложение.
- Пользователь открывает ссылку.
- Сначала сайт выглядит как красивая интерактивная книга.
- Потом после финала сайт ломается и превращается в хоррор/игру.

Технологии:
- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- Howler.js
- react-pageflip или кастомный page-flip
- Phaser для хоррор-мини-игры
- framer-motion можно использовать для UI-анимаций

Ассеты:
- Обложка: public/assets/cover
- Страницы книги: public/assets/pages
- Карты игры: public/assets/cards
- Звуки: public/assets/sounds
- Исходники/архивы: public/assets/source
- Русские названия файлов допустимы.
- Нужно создать TypeScript-карту ассетов, чтобы код обращался к понятным ключам, а не к хаотичным именам файлов.

Обязательные сцены:
1. Интерактивная загрузка с необычной анимацией и звуками.
2. Красивая главная с темным фоном и спокойной музыкой.
3. Парящая книга по центру.
4. Книга реагирует на курсор.
5. По клику книга раскрывается и приближается.
6. Чтение 40 страниц по порядку.
7. Page-flip эффект.
8. Загиб уголков страниц при наведении/поднесении мышки.
9. 5 разных звуков перелистывания, случайный звук каждый раз.
10. После страницы 40 книга закрывается.
11. Музыка прекращается.
12. Книга быстро закрывается с хлопком.
13. Плашка “получена очивка” в стиле Minecraft.
14. Сайт ломается: кнопки падают, фон трескается, пиксели/куски падают вниз.
15. Печатающийся текст: “НЕТ! ты не должна была это видеть (кликни для далее)”.
16. После клика новый текст: “НУ РАЗ ТАК, ДАВАЙ ПОИГРАЕМ, ВЫБЕРИ СВОЮ СМЕРТЬ (клик)”.
17. Таймер 10 секунд.
18. 3 карты игры: PAC-MAN, MAZE, STATIC.
19. Карты подсвечиваются при наведении.
20. Под картами анимированный дым.
21. Если время вышло — кровавый GAME OVER.
22. Если игра выбрана — запускается темная жуткая мини-игра.
23. У игрока 2 попытки.
24. При проигрыше — GAME OVER.
25. При победе игра рушится.
26. Печатается текст: “ЖАЛКООО, я ведь так хотел крови”.
27. После клика текст стирается.
28. Экран тухнет.
29. Вторая ачивка: “ты прошел(а) игру су**а”.
30. Возвращение на главную, но теперь она испорченная.
31. Книга жуткая, кривая, закрытая.
32. Музыка меняется на жуткую.
33. При клике книга трясется как закрытая на замок.
34. Появляется текст: “не шли меня, глава 2 скоро, проваливай!”.
35. При повторном клике эффект повторяется со звуком закрытой книги.

Правила разработки:
- Работай по этапам.
- Не реализуй весь сайт за один запрос.
- Не пиши весь проект в один файл.
- Делай компонентно.
- После каждого этапа запускай проверку.
- Не используй npm audit fix --force без отдельного разрешения.
- Не удаляй ассеты.
- Не переименовывай файлы без необходимости.
- Если переименование нужно, сначала создай безопасный скрипт и объясни план.

Что считать готовым:
- npm run dev запускается без ошибок.
- npm run build проходит.
- Все сцены из docs/сайт.txt сохранены.
- Страницы книги идут строго по порядку.
- Звуки подключены через карту ассетов.
- Код можно развивать дальше.
